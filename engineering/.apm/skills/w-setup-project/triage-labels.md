# 分诊标签

各技能用五个规范的分诊角色来表述。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 规范角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整描述，可由 AFK agent 接手 |
| `ready-for-human` | `ready-for-human` | 需人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色时（例如「打上可用于 AFK 的分诊标签」），使用本表中对应的标签字符串。

改右列即可适配你实际使用的词表。
